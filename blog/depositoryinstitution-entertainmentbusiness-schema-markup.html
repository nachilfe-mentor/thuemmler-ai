DepositoryInstitution & EntertainmentBusiness Schema Markup: Bank und Unterhaltung für Google

Shift07 Team
1. Mai 2026
12 Min. Lesezeit
Schema Markup

Banken und Unterhaltungsbetriebe — zwei sehr unterschiedliche Branchen, die in Google-Suchergebnissen oft schlecht sichtbar sind. Wer für eine Bank, eine Kreditgenossenschaft, ein Kino, einen Nightclub oder einen Comedy-Club eine Website betreibt, kann mit den richtigen Schema-Markup-Typen deutlich mehr Präsenz in den SERPs erzielen. In diesem Artikel erkläre ich dir, wie DepositoryInstitution Schema Markup und EntertainmentBusiness Schema Markup korrekt implementiert werden — inklusive vollständiger JSON-LD-Codebeispiele.

Beide Typen sind Unterklassen von LocalBusiness und erben alle Standard-Properties wie name, address, telephone und openingHoursSpecification. Zusätzlich gibt es je nach Typ spezifische Properties, die Googles Rich-Results-Algorithmus zur korrekten Kategorisierung nutzt.

Was ist DepositoryInstitution?

DepositoryInstitution ist ein Schema.org-Typ für Finanzinstitute, die Einlagen annehmen — also klassische Banken, Sparkassen, Volksbanken, Kreditgenossenschaften und ähnliche Geldinstitute. Die vollständige Typhierarchie sieht so aus:

  • DepositoryInstitution (Obertyp für alle Einlagenkreditinstitute)
    • BankOrCreditUnion → für Universalbanken und Genossenschaftsbanken

Der Unterschied zu FinancialService ist wichtig: Während FinancialService für Versicherungsmakler, Finanzberater und andere Dienstleister gilt, steht DepositoryInstitution explizit für Institutionen, die das Einlagengeschäft betreiben — also eine Banklizenz haben.

Wann DepositoryInstitution verwenden?

  • Volksbanken und Raiffeisenbanken
  • Sparkassen und Kreissparkassen
  • Privatbanken und Direktbanken
  • Kreditgenossenschaften
  • Genossenschaftsbanken
  • Bausparkassen (wenn sie Einlagen annehmen)

DepositoryInstitution JSON-LD: Vollständiges Beispiel

Das folgende Beispiel zeigt ein vollständiges Schema für eine Volksbank-Filiale mit Öffnungszeiten, Serviceleistungen und Geo-Koordinaten:

{
  "@context": "https://schema.org",
  "@type": "BankOrCreditUnion",
  "name": "Volksbank Rhein-Ruhr eG – Filiale Duisburg-Mitte",
  "url": "https://www.volksbank-rhein-ruhr.de/filiale-duisburg-mitte",
  "telephone": "+49 203 987654",
  "email": "filiale-duisburg@volksbank-rhein-ruhr.de",
  "description": "Ihre Volksbank Filiale in Duisburg-Mitte: persönliche Beratung, Girokonten, Spar- und Anlageprodukte sowie Kredite für Privat- und Firmenkunden.",
  "image": "https://www.volksbank-rhein-ruhr.de/images/filiale-duisburg.jpg",
  "logo": "https://www.volksbank-rhein-ruhr.de/logo.png",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Königstraße 45",
    "addressLocality": "Duisburg",
    "postalCode": "47051",
    "addressCountry": "DE"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": 51.4344,
    "longitude": 6.7623
  },
  "openingHoursSpecification": [
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Friday"],
      "opens": "09:00",
      "closes": "17:00"
    },
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": "Thursday",
      "opens": "09:00",
      "closes": "18:00"
    }
  ],
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "Bankdienstleistungen",
    "itemListElement": [
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "Girokonto" } },
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "Baufinanzierung" } },
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "Anlageberatung" } },
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "Ratenkredit" } }
    ]
  },
  "areaServed": {
    "@type": "City",
    "name": "Duisburg"
  },
  "sameAs": [
    "https://www.facebook.com/volksbank-rhein-ruhr",
    "https://maps.google.com/?cid=123456789"
  ]
}

Wichtige Properties für Banken

  • hasOfferCatalog: Liste der angebotenen Bankprodukte (Girokonto, Kredit, Sparen etc.)
  • areaServed: Einzugsgebiet der Filiale
  • branchOf: Falls es sich um eine Filiale handelt, Verlinkung zur Muttergesellschaft
  • numberOfEmployees: Anzahl Mitarbeiter (optional, erhöht Vertrauenssignal)
  • foundingDate: Gründungsjahr der Bank
  • currenciesAccepted: Akzeptierte Währungen
  • paymentAccepted: Akzeptierte Zahlungsmethoden (z.B. „Kreditkarte, Überweisung")

Für Banken-Ketten: branchOf richtig nutzen

Wenn du Schema für eine Filiale einer größeren Bank implementierst, solltest du branchOf verwenden, um die hierarchische Beziehung zu dokumentieren:

{
  "@context": "https://schema.org",
  "@type": "BankOrCreditUnion",
  "name": "Sparkasse Duisburg – Filiale Stadtmitte",
  "branchOf": {
    "@type": "BankOrCreditUnion",
    "name": "Sparkasse Duisburg",
    "url": "https://www.sparkasse-duisburg.de",
    "legalName": "Stadtsparkasse Duisburg"
  },
  "address": { ... }
}

Was ist EntertainmentBusiness?

EntertainmentBusiness ist der Schema.org-Typ für Unterhaltungsbetriebe — also Orte, an denen Menschen ihre Freizeit verbringen und sich unterhalten lassen. Die Typhierarchie ist besonders reichhaltig:

  • EntertainmentBusiness (Obertyp)
    • AdultEntertainment → für Erwachsenenunterhaltung
    • AmusementPark → für Freizeitparks
    • ArtGallery → für Kunstgalerien
    • Casino → für Spielkasinos
    • ComedyClub → für Kabarett und Comedy
    • MovieTheater → für Kinos
    • NightClub → für Diskotheken und Clubs

Diese Vielfalt macht EntertainmentBusiness zu einem der nützlichsten Schema-Typen für die Freizeitwirtschaft. Jeder Sub-Typ gibt Google präzise Signale über das Geschäftsmodell.

EntertainmentBusiness: NightClub und ComedyClub

Diskotheken und Clubs haben besondere Anforderungen, da Veranstaltungen und Events eine große Rolle spielen. Kombiniere NightClub mit Event-Schema für maximale Sichtbarkeit:

  "url": "https://www.tresorberlin.com",

Häufige Fehler bei DepositoryInstitution und EntertainmentBusiness

Bei der Implementierung dieser Schema-Typen tauchen immer wieder dieselben Fehler auf:

  • Falscher Typ gewählt: Eine Sparkasse als FinancialService statt BankOrCreditUnion zu taggen ist technisch nicht falsch, aber semantisch ungenau. Google kann die Einrichtung schlechter kategorisieren.
  • Kein aggregateRating: Besonders für Kinos, Clubs und Galerien sind Bewertungen ein wichtiges Vertrauenssignal. Das Weglassen verschenkt potenzielle Sternebewertungen in den SERPs.
  • Fehlende Öffnungszeiten: Bei Unterhaltungsbetrieben mit unregelmäßigen Zeiten (z.B. Clubs die nur Fr/Sa öffnen) müssen die Öffnungszeiten korrekt als Array implementiert werden.
  • screenCount für Kinos vergessen: Diese spezifische Property wird von vielen Kino-Websites ignoriert, obwohl Google sie aktiv auswertet.
  • Events nicht verlinkt: Wenn ein Club oder ein Kino aktuell Veranstaltungen hat, sollte die event-Property auf das Event Schema Markup zeigen.

Validierung und Testing

Nach der Implementierung solltest du das Schema in diesen drei Tools testen:

  1. Google Rich Results Test: schema.org/docs/richresults — prüft ob Google das Schema korrekt verarbeitet
  2. Schema.org Validator: validator.schema.org — zeigt Fehler und Warnungen nach Schema.org-Standard
  3. Shift07 SEO-Analyse: Mit unserem JSON-LD Structured Data Validator kannst du das Schema kostenlos prüfen

Häufige Validierungsfehler: falsche Datumsformate (ISO 8601 ist Pflicht), fehlende Pflichtfelder bei bestimmten Typen, und ungültige @type-Werte (Groß-/Kleinschreibung beachten!).

Schema für Banken und Finanzinstitute: Compliance-Hinweis

Bei der Implementierung von Schema für Banken gibt es einen regulatorischen Aspekt: Bankdienstleistungen unterliegen dem Wettbewerbsrecht und der BaFin-Regulierung. Das bedeutet:

  • Im description-Feld keine konkreten Zinsangaben machen (können veralten und irreführend wirken)
  • priceRange für Bankkonten ist schwierig — besser weglassen oder auf Preisseiten verlinken
  • Bei hasOfferCatalog nur allgemeine Leistungsbeschreibungen, keine Konditionen

Das ist kein technisches Problem des Schema Markups, aber ein wichtiger Hinweis für den redaktionellen Umgang damit.

Checkliste: DepositoryInstitution & EntertainmentBusiness Schema

Verwende diese Checkliste vor der Veröffentlichung:

  • ✅ Richtiger Sub-Typ gewählt (BankOrCreditUnion, MovieTheater, NightClub etc.)
  • ✅ name, address, telephone korrekt ausgefüllt
  • ✅ openingHoursSpecification als Array mit allen Wochentagen
  • ✅ geo mit exakten Koordinaten (von Google Maps kopieren)
  • ✅ aggregateRating eingebunden (wenn Bewertungen vorhanden)
  • ✅ Für Kinos: screenCount angegeben
  • ✅ Für Unterhaltungsbetriebe: aktuelle event-Verknüpfung
  • ✅ Für Banken: hasOfferCatalog mit Serviceleistungen
  • ✅ sameAs mit Google Maps URL und Social Media
  • ✅ Validierung im Rich Results Test bestanden

Mit korrekt implementiertem Schema Markup heben sich Banken und Unterhaltungsbetriebe deutlich von der Konkurrenz ab — besonders in lokalen Suchen wie "Kino in der Nähe" oder "Bank Filiale München" sind Rich Results ein entscheidender Wettbewerbsvorteil.
