1. Die MedicalEntity-Typhierarchie im Überblick

MedicalEntity ist der übergeordnete Schema.org-Typ für alle medizinischen Entitäten. Er ist der Basistyp für eine breite Hierarchie von Untertypen, die spezifische Aspekte des Gesundheitswesens beschreiben. Im Gegensatz zu allgemeinen strukturierten Daten sind MedicalEntity-Typen ausschließlich für medizinische Inhalte gedacht.

MedicalEntity
├── Drug (Arzneimittel)
│ ├── DietarySupplement (Nahrungsergänzung)
│ └── PrescriptionOnly ← Property
├── MedicalCondition (Erkrankungen)
│ ├── InfectiousDisease
│ ├── MedicalSign / MedicalSymptom
│ └── MedicalIndication
├── MedicalProcedure (Eingriffe)
│ ├── DiagnosticProcedure
│ ├── SurgicalProcedure
│ ├── TherapeuticProcedure
│ └── PhysicalActivity ← Untertyp
├── MedicalDevice (Medizingeräte)
├── MedicalTest (Diagnose-Tests)
│ ├── BloodTest
│ ├── ImagingTest
│ ├── PathologyTest
│ └── PhysicalExam
└── AnatomicalStructure (Anatomie)
├── Bone, Muscle, Nerve, ...
└── AnatomicalSystem

Alle MedicalEntity-Untertypen teilen gemeinsame Properties:

  • code: Medizinische Klassifikationscodes (ICD-10, SNOMED CT, etc.)
  • guideline: Medizinische Leitlinien, die diesen Typ behandeln
  • legalStatus: Rechtlicher Status (z. B. verschreibungspflichtig)
  • medicineSystem: Medizinsystem (Allopathie, Homöopathie, etc.)
  • recognizingAuthority: Anerkennende Behörde (z. B. EMA, BfArM)
  • relevantSpecialty: Medizinische Fachrichtung
  • study: Verweis auf klinische Studien

2. Drug: Arzneimittel strukturiert beschreiben

Der Typ Drug beschreibt Arzneimittel, Medikamente und Wirkstoffe. Er eignet sich für Apotheken-Websites, Beipackzettel-Portale und pharmazeutische Fachinformationen.

Drug-spezifische Properties

Property Beschreibung
activeIngredientAktiver Wirkstoff des Medikaments
administrationRouteVerabreichungsweg (oral, intravenös, topisch, etc.)
availableStrengthVerfügbare Wirkstärken (DrugStrength-Objekt)
clinicalPharmacologyKlinisch-pharmakologische Beschreibung
dosageFormDarreichungsform (Tablette, Kapsel, Lösung, etc.)
drugClassWirkstoffklasse (z. B. Betablocker, SSRI)
drugUnitEinheit der Wirkstärke (mg, ml, etc.)
foodWarningWarnhinweise zu Lebensmittelwechselwirkungen
interactingDrugWechselwirkungen mit anderen Medikamenten
isProprietaryIst es ein Markenmedikament? (true/false)
prescriptionStatusPrescriptionStatus: OTC oder verschreibungspflichtig
warningAllgemeine Warnhinweise

JSON-LD Beispiel: Arzneimittel

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Drug",
  "name": "Ibuprofen 400 mg",
  "description": "Ibuprofen ist ein nicht-steroidales Antirheumatikum (NSAR) zur Behandlung von leichten bis moderaten Schmerzen, Entzündungen und Fieber.",
  "activeIngredient": "Ibuprofen",
  "dosageForm": "Filmtablette",
  "drugUnit": "mg",
  "availableStrength": {
    "@type": "DrugStrength",
    "activeIngredient": "Ibuprofen",
    "strengthValue": 400,
    "strengthUnit": "mg"
  },
  "administrationRoute": "oral",
  "prescriptionStatus": "OTC",
  "isProprietary": false,
  "drugClass": {
    "@type": "DrugClass",
    "name": "Nicht-steroidales Antirheumatikum (NSAR)"
  },
  "warning": "Nicht für Kinder unter 12 Jahren ohne ärztlichen Rat. Nicht bei bekannter Überempfindlichkeit gegen Ibuprofen.",
  "foodWarning": "Einnahme mit Mahlzeiten empfohlen, um Magenreizungen zu vermeiden.",
  "code": {
    "@type": "MedicalCode",
    "codeValue": "M01AE01",
    "codingSystem": "ATC"
  },
  "legalStatus": {
    "@type": "DrugLegalStatus",
    "applicableLocation": "DE",
    "legalStatus": "OTC"
  }
}
</script>

3. MedicalCondition: Krankheitsbilder für Google

MedicalCondition beschreibt Erkrankungen, Syndrome und medizinische Zustände. Gesundheitsportale, Kliniken und Arztpraxen nutzen diesen Typ für Patienteninformationsseiten. Wir haben die Grundlagen bereits im Artikel MedicalEntity Schema Markup behandelt — hier gehen wir in die Tiefe.

MedicalCondition-spezifische Properties

Property Beschreibung
associatedAnatomyBetroffene Körperregion oder anatomische Struktur
causeUrsache(n) der Erkrankung (MedicalCause)
differentialDiagnosisDifferenzialdiagnosen (DDxElement)
epidemiologyEpidemiologische Angaben (Häufigkeit, Risikofaktoren)
expectedPrognosisErwartete Prognose bei typischem Verlauf
naturalProgressionNatürlicher Verlauf ohne Behandlung
pathophysiologyPathophysiologische Beschreibung
possibleTreatmentMögliche Behandlungen (MedicalTherapy)
primaryPreventionPrimärprävention (Vorbeugung vor Erkrankung)
riskFactorRisikofaktoren (MedicalRiskFactor)
secondaryPreventionSekundärprävention (nach Diagnose)
signOrSymptomSymptome und klinische Zeichen
stageKrankheitsstadien (MedicalConditionStage)
typicalTestTypische Diagnosetests für diese Erkrankung

  "infectiousAgent": "Influenza-Virus (Typ A, B)",
  "infectiousAgentClass": "Virus",
  "transmissionMethod": "Tröpfcheninfektion, Schmierinfektion",
  "signOrSymptom": [
    {
      "@type": "MedicalSymptom",
      "name": "Plötzliches hohes Fieber (38–41 °C)"
    },
    {
      "@type": "MedicalSymptom",
      "name": "Starke Gliederschmerzen"
    },
    {
      "@type": "MedicalSymptom",
      "name": "Trockener Husten"
    }
  ],
  "riskFactor": [
    {
      "@type": "MedicalRiskFactor",
      "name": "Ältere Menschen (>65 Jahre)"
    },
    {
      "@type": "MedicalRiskFactor",
      "name": "Immungeschwächte Personen"
    }
  ],
  "primaryPrevention": {
    "@type": "MedicalTherapy",
    "name": "Influenza-Schutzimpfung (jährlich empfohlen)"
  },
  "code": {
    "@type": "MedicalCode",
    "codeValue": "J10",
    "codingSystem": "ICD-10"
  },
  "relevantSpecialty": {
    "@type": "MedicalSpecialty",

  }
}
</script>

Untertypen von MedicalCondition

InfectiousDisease

Für Infektionskrankheiten. Zusätzliche Properties: infectiousAgent, infectiousAgentClass, transmissionMethod

MedicalSign / MedicalSymptom

Für einzelne Krankheitssymptome oder klinische Zeichen als eigenständige Schema-Objekte

MedicalIndication

Medizinische Indikation für eine Behandlung (z. B. "Hypertonie als Indikation für Betablocker")

MedicalContraindication

Kontraindikationen — wird häufig als Property bei Drug oder MedicalProcedure eingesetzt

4. MedicalProcedure: Eingriffe und Therapien vertieft

Den Typ MedicalProcedure und MedicalTherapy haben wir bereits im Grundlagenartikel behandelt. Hier vertiefen wir die wichtigsten Untertypen:

DiagnosticProcedure

Für diagnostische Maßnahmen wie Blutabnahme, MRT oder Endoskopie. Enthält die Property usedToDiagnose für die zugehörige Erkrankung.

{
  "@type": "DiagnosticProcedure",
  "name": "Magnetresonanztomographie (MRT) des Kniegelenks",
  "usedToDiagnose": {
    "@type": "MedicalCondition",
    "name": "Meniskusriss"
  },
  "bodyLocation": "Kniegelenk",
  "preparation": "Keine metallischen Implantate oder Herzschrittmacher"
}

SurgicalProcedure

Für chirurgische Eingriffe. Eignet sich ideal für Kliniken und Chirurgie-Praxen.

{
  "@type": "SurgicalProcedure",
  "name": "Arthroskopische Meniskusresektion",
  "bodyLocation": "Kniegelenk",
  "followup": "Physiotherapie für 6-8 Wochen nach dem Eingriff",
  "howPerformed": "Minimalinvasiver Eingriff unter Vollnarkose oder Spinalanästhesie"
}

TherapeuticProcedure

Für therapeutische Maßnahmen wie Physiotherapie, Strahlentherapie oder medikamentöse Therapien.

{
  "@type": "TherapeuticProcedure",
  "name": "Manuelle Therapie bei Rückenschmerzen",
  "indication": {
    "@type": "MedicalIndication",
    "name": "Chronische lumbale Rückenschmerzen"
  },
  "drug": {
    "@type": "Drug",
    "name": "Keine Medikamente erforderlich"
  }
}

5. MedicalDevice: Medizinische Geräte

MedicalDevice beschreibt medizinische Geräte und Hilfsmittel — von Blutdruckmessgeräten über Prothesen bis hin zu Herzschrittmachern. Besonders nützlich für Medizintechnik-Hersteller und Sanitätshäuser.

Property Beschreibung
adverseOutcomeMögliche Nebenwirkungen oder Risiken bei der Anwendung
contraindicationKontraindikationen für das Gerät
indicationMedizinische Indikation für die Anwendung
postOpPostoperative Pflege nach Geräteeinsatz
preOpPräoperative Vorbereitung
purposeMedizinischer Zweck des Geräts

{
  "@context": "https://schema.org",
  "@type": "MedicalDevice",

  "description": "Ein kleines Gerät, das unter die Haut platziert wird und kontinuierlich den Blutzuckerspiegel misst und auf einem Empfänger anzeigt.",
  "indication": {
    "@type": "MedicalIndication",
    "name": "Diabetes mellitus Typ 1 und Typ 2"
  },
  "contraindication": "Nicht für Patienten mit Nickel-Allergie empfohlen",
  "purpose": {
    "@type": "MedicalTherapy",
    "name": "Kontinuierliche Blutzuckerüberwachung zur verbesserten Diabeteskontrolle"
  },
  "recognizingAuthority": {
    "@type": "Organization",
    "name": "FDA / CE-Kennzeichnung"
  }
}
</script>

6. MedicalTest: Diagnosen und Tests

MedicalTest ist ein eigenständiger Typ (neben DiagnosticProcedure) für standardisierte medizinische Tests. Die Untertypen decken unterschiedliche Diagnoseverfahren ab:

BloodTest

Blutuntersuchungen wie Blutbild, Cholesterin, HbA1c. Properties: normalRange, usedToDiagnose

ImagingTest

Bildgebende Verfahren: Röntgen, MRT, CT, Ultraschall. Enthält imagingTechnique

PathologyTest

Gewebeuntersuchungen und Biopsien für histologische Diagnosen

PhysicalExam

Körperliche Untersuchungsmethoden wie Palpation, Auskultation, Reflexprüfung

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BloodTest",
  "name": "HbA1c-Test (Langzeit-Blutzucker)",
  "description": "Der HbA1c-Wert zeigt den durchschnittlichen Blutzucker der letzten 2-3 Monate. Wichtiger Kontrollparameter bei Diabetes mellitus.",
  "normalRange": "Unter 5,7 % = normal; 5,7–6,4 % = Prädiabetes; ≥ 6,5 % = Diabetes",
  "usedToDiagnose": {
    "@type": "MedicalCondition",
    "name": "Diabetes mellitus"
  },
  "relevantSpecialty": {
    "@type": "MedicalSpecialty",
    "name": "Diabetologie"
  }
}
</script>

7. AnatomicalStructure: Körperteile und Systeme

AnatomicalStructure beschreibt Körperteile, Organe und anatomische Systeme. Dieser Typ eignet sich für medizinische Enzyklopädien, Anatomie-Websites und Klinik-Portale, die Körperstrukturen erklären.

Property Beschreibung
associatedPathophysiologyPathophysiologische Zusammenhänge dieser Struktur
bodyLocationLage im Körper (z. B. "Oberschenkel", "Thorax")
connectedToVerbundene Strukturen (andere AnatomicalStructure)
diagramAnatomische Darstellung / Diagramm (ImageObject)
functionBiologische Funktion der Struktur
partOfSystemAnatomisches System (AnatomicalSystem)
relatedConditionVerwandte Erkrankungen dieser Struktur
relatedTherapyTherapien die diese Struktur betreffen
subStructureUnterstrukturen (z. B. Kammern des Herzens)

8. Untertypen kombinieren: vollständige Gesundheitsseite

Für eine umfassende medizinische Informationsseite (z. B. eine Erkrankungsseite auf einem Klinikportal) lassen sich mehrere MedicalEntity-Untertypen sinnvoll kombinieren: 

<script type="application/ld+json">
[
  {
    "@context": "https://schema.org",
    "@type": "MedicalCondition",
    "name": "Typ-2-Diabetes",
    "description": "Chronische Stoffwechselerkrankung mit Insulinresistenz und relativem Insulinmangel.",
    "code": { "@type": "MedicalCode", "codeValue": "E11", "codingSystem": "ICD-10" },
    "typicalTest": { "@type": "BloodTest", "name": "Nüchternblutzucker" },
    "possibleTreatment": { "@type": "Drug", "name": "Metformin" }
  },
  {
    "@context": "https://schema.org",
    "@type": "MedicalWebPage",
    "name": "Typ-2-Diabetes: Ursachen, Symptome und Behandlung",
    "url": "https://www.klinik-beispiel.de/erkrankungen/typ-2-diabetes",
    "lastReviewed": "2026-03-01",
    "reviewedBy": {
      "@type": "Person",
      "name": "Dr. med. M. Müller",
      "hasCredential": "Facharzt für Innere Medizin, Diabetologie"
    },
    "about": {
      "@type": "MedicalCondition",
      "name": "Typ-2-Diabetes"
    },
    "audience": {
      "@type": "MedicalAudience",
      "audienceType": "Patient"
    }
  }
]
</script>

Der Typ MedicalWebPage ist hier besonders wichtig: Er signalisiert Google, dass es sich um eine medizinische Informationsseite handelt, und ermöglicht zusätzliche Properties wie lastReviewed und reviewedBy — für die E-E-A-T-Signale, die für Gesundheitsinhalte besonders relevant sind.

9. Google-spezifische Anforderungen für Medical Content

Google hat für medizinische Inhalte besonders strenge Qualitätsrichtlinien (YMYL — Your Money or Your Life). Beim Einsatz von MedicalEntity-Markup beachte:

⚠️ Medizinische Genauigkeit

Google prüft medizinische Inhalte auf Genauigkeit und Aktualität. Schema Markup kann keine inhaltlichen Qualitätsmängel ausgleichen. Der Inhalt muss von ausgewiesenen Experten verfasst oder geprüft sein.

⚠️ E-E-A-T für Gesundheitsinhalte

Experience, Expertise, Authoritativeness, Trustworthiness sind für YMYL-Seiten entscheidend. Nutze MedicalWebPage.reviewedBy mit einem echten Arzt und gib dessen Qualifikationen an.

✓ Empfohlene Kombination: MedicalWebPage + MedicalCondition

Die Kombination von MedicalWebPage (Seiten-Metadaten) mit dem inhaltlichen Typ (z. B. MedicalCondition) ist die beste Praxis für Gesundheitsseiten. Nutze about, um beide zu verknüpfen.

✓ ICD-10 Codes angeben

Wenn du code mit dem ICD-10-Code (z. B. "E11" für Typ-2-Diabetes) angibst, ermöglicht das Google eine präzisere Klassifikation. Das stärkt die Topical Authority für medizinische Suchbegriffe.

10. Fazit und Checkliste

Die MedicalEntity-Typhierarchie ist umfangreich, aber logisch aufgebaut. Mit dem richtigen Untertyp und den passenden Properties kannst du Google präzise mitteilen, welche Art von medizinischer Information deine Seite enthält — und damit für relevante Gesundheitssuchanfragen besser ranken.

Checkliste: MedicalEntity Schema richtig implementieren

  • ✓ Richtigen Untertyp wählen (Drug, MedicalCondition, MedicalProcedure, MedicalDevice, MedicalTest, AnatomicalStructure)
  • ✓ ICD-10 oder andere Klassifikationscodes bei code angeben
  • ✓ relevantSpecialty angeben für die medizinische Fachrichtung
  • ✓ MedicalWebPage mit reviewedBy für E-E-A-T kombinieren
  • ✓ Alle Schema-Angaben stimmen mit sichtbarem Inhalt überein
  • ✓ Inhalte von medizinischen Experten verfasst oder geprüft
  • ✓ Validierung mit dem JSON-LD Validator und Google Rich Results Test
