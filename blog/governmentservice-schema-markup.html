1. Was ist GovernmentService Schema?

GovernmentService (schema.org/GovernmentService) ist ein Schema.org-Typ für Dienstleistungen, die von staatlichen oder öffentlichen Stellen erbracht werden. Er ist ein Untertyp von Service und beschreibt konkrete Bürgerdienste — von der Personalausweis-Beantragung über die Kfz-Zulassung bis zur Beratung durch das Jugendamt.

Für Behörden, Kommunen und Verwaltungsportale ist GovernmentService Schema besonders relevant, weil Bürger zunehmend über Google nach konkreten Dienstleistungen suchen: „Personalausweis beantragen München", „Kfz-Zulassung Hamburg online", „Baugenehmigung Köln Antrag". Korrekt implementiertes Schema Markup hilft Google, diese Suchanfragen direkt der richtigen Dienstleistungsseite zuzuordnen.

GovernmentService in Googles Knowledge Graph

Google nutzt GovernmentService-Daten für den Knowledge Graph und für lokale Suchergebnisse. Besonders areaServed und serviceType helfen dabei, Dienste geografisch zuzuordnen und thematisch einzuordnen.

2. Abgrenzung: GovernmentService vs. GovernmentOrganization

Ein häufiger Fehler ist es, GovernmentService und GovernmentOrganization zu verwechseln. Hier die klare Unterscheidung:

Typ Beschreibt Beispiele
GovernmentOrganization Die Institution selbst Stadtamt München, Finanzamt Berlin-Mitte, Bundesagentur für Arbeit
GovernmentService Eine konkrete Leistung dieser Institution Personalausweis beantragen, Einkommensteuererklärung abgeben, Arbeitslosenantrag stellen

Auf einer dedizierten Seite für eine Dienstleistung (z. B. „Personalausweis beantragen") setzt du GovernmentService. Auf der Übersichtsseite des Amtes oder der Behörde selbst setzt du GovernmentOrganization. Beide Schemas können über die Property provider miteinander verknüpft werden.

3. Die wichtigsten Properties im Überblick

Property Typ Bedeutung
name Text Bezeichnung der Dienstleistung (Pflicht)
description Text Kurzbeschreibung der Leistung und ihrer Zielgruppe
serviceType Text Art der Dienstleistung (z. B. „Personalausweis", „Kfz-Zulassung")
areaServed AdministrativeArea / Text Geografisches Einzugsgebiet (Gemeinde, Landkreis, Bundesland)
provider GovernmentOrganization / Organization Die anbietende Behörde oder Organisation
availableChannel ServiceChannel Zugangswege (online, telefonisch, persönlich)
category Text Kategorisierung (z. B. „Bürgerservice", „Sozialleistungen")
audience Audience Zielgruppe der Dienstleistung (z. B. „Bürger", „Unternehmen")
termsOfService Text / URL Link zu Nutzungsbedingungen oder Rechtsgrundlagen
serviceOutput Thing Ergebnis der Leistung (z. B. ausgestelltes Dokument)
hoursAvailable OpeningHoursSpecification Verfügbarkeitszeiten der Dienstleistung
url URL Direkte URL zur Dienstleistungsseite

4. ServiceChannel: Online, Telefon, persönlich

ServiceChannel ist das wichtigste verschachtelte Objekt in GovernmentService. Es beschreibt, auf welchem Weg Bürger die Dienstleistung in Anspruch nehmen können. Für viele Behörden gibt es mehrere Kanäle parallel:

Online-Portal

Digitaler Zugang über ein Bürgerportal oder eine Web-App

serviceUrl: "https://..."

Telefonisch

Hotline oder direkte Durchwahl für Terminvereinbarungen

contactPoint.telephone

Persönlich / vor Ort

Besuch der Behörde mit oder ohne Termin

serviceLocation.address

Jeder Kanal wird als separates ServiceChannel-Objekt im Array availableChannel angegeben. Du kannst und solltest mehrere Kanäle gleichzeitig angeben, wenn die Behörde mehrere Zugangswege anbietet.

5. JSON-LD-Beispiele: Bürgeramt, Finanzamt, Jugendamt

5.1 Bürgeramt: Personalausweis beantragen

{
  "@context": "https://schema.org",
  "@type": "GovernmentService",
  "name": "Personalausweis beantragen",
  "description": "Beantragung eines neuen Personalausweises für Personen ab 16 Jahren mit Hauptwohnsitz in München. Der Personalausweis wird in der Regel innerhalb von 3–4 Wochen ausgestellt.",
  "serviceType": "Personalausweis",
  "category": "Bürgerservice",
  "url": "https://www.muenchen.de/buergerservice/personalausweis",
  "areaServed": {
    "@type": "City",
    "name": "München",
    "sameAs": "https://www.wikidata.org/wiki/Q1726"
  },
  "provider": {
    "@type": "GovernmentOrganization",
    "name": "Kreisverwaltungsreferat München",
    "url": "https://www.muenchen.de/rathaus/kreisverwaltungsreferat.html"
  },
  "availableChannel": [
    {
      "@type": "ServiceChannel",
      "name": "Online-Termin",
      "serviceUrl": "https://terminvereinbarung.muenchen.de/kvr",
      "serviceType": "Online"
    },
    {
      "@type": "ServiceChannel",
      "name": "Persönlich im KVR",
      "serviceType": "Vor Ort",
      "serviceLocation": {
        "@type": "Place",
        "name": "Bürgeramt Ruppertstraße",
        "address": {
          "@type": "PostalAddress",
          "streetAddress": "Ruppertstraße 19",
          "postalCode": "80337",
          "addressLocality": "München",
          "addressCountry": "DE"
        }
      }
    }
  ],
  "hoursAvailable": [
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday"],
      "opens": "08:00",
      "closes": "17:00"
    },
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": "Friday",
      "opens": "08:00",
      "closes": "13:00"
    }
  ],
  "serviceOutput": {
    "@type": "Thing",
    "name": "Personalausweis (PA)"
  }
}

6. Kombination mit LocalBusiness und ContactPoint

Für maximale SEO-Wirkung kombinierst du GovernmentService mit weiteren Schema-Typen. Die gängigste und wirkungsvollste Kombination:

GovernmentService + LocalBusiness

Nutze provider.@type: GovernmentOrganization und ergänze address und geo-Koordinaten. So erscheint die Behörde auch in lokalen Suchergebnissen und Google Maps.

GovernmentService + ContactPoint

Das ContactPoint-Schema im ServiceChannel gibt Telefonnummern, E-Mail-Adressen und Sprachoptionen strukturiert an. Besonders für barrierefreie Behörden-Websites wichtig.

GovernmentService + OpeningHoursSpecification

Öffnungszeiten über hoursAvailable helfen Google, Verfügbarkeit direkt in der Suche anzuzeigen. Besonders bei Ämtern mit abweichenden Öffnungszeiten und Mittagspausen wichtig.

7. E-Government und SEO: Warum Behörden Schema brauchen

Öffentliche Verwaltungen werden zunehmend im Netz gesucht. Laut Studien der Initiative D21 suchen über 70 % der Deutschen nach Behördendiensten zunächst über Suchmaschinen. Wer bei einer Suche nach „Führerschein umtauschen Hamburg" nicht auf den ersten Plätzen erscheint, verliert Bürger an inoffizielle Drittseiten mit teils veralteten Informationen.

GovernmentService Schema Markup bietet Behörden drei konkrete Vorteile:

  1. Bessere Sichtbarkeit bei behördenspezifischen Suchanfragen durch semantisch klare Typisierung
  2. Knowledge-Graph-Einträge: Google kann Dienste in Infoboxen (Rich Cards) darstellen
  3. Vertrauenssignal: Korrekte, aktuell gehaltene strukturierte Daten signalisieren Qualität und Aktualität

Tipp für kommunale Websites

Viele Kommunen betreiben ein einziges Portal mit hunderten Dienstleistungsseiten. Nutze ein CMS-Template, das GovernmentService-Schema automatisch pro Seite generiert — basierend auf den hinterlegten Metadaten jeder Dienstleistung. Das spart enormen manuellen Aufwand.

8. Häufige Fehler und Best Practices

❌ Fehler: GovernmentOrganization statt GovernmentService auf Dienstleistungsseiten

Auf der Seite „Personalausweis beantragen" gehört GovernmentService, nicht GovernmentOrganization. Letzteres beschreibt die Behörde als Institution, nicht den Dienst.

❌ Fehler: areaServed fehlt oder ist zu unspezifisch

Ohne areaServed kann Google den Dienst nicht geografisch einordnen. „Deutschland" als areaServed ist für einen lokalen Bürgerservice falsch — gib die Gemeinde oder den Landkreis an.

❌ Fehler: Kein ServiceChannel für Online-Angebote

Wenn die Behörde einen Online-Antrag anbietet, muss das über availableChannel mit serviceUrl angegeben sein. Nur so kann Google den digitalen Zugang korrekt verknüpfen.

✅ Best Practice: serviceType als sprechenden Text wählen

Wähle für serviceType den Begriff, den Bürger tatsächlich suchen: „Personalausweis" statt „Identitätsdokument". Google nutzt diesen Text für die semantische Zuordnung.

✅ Best Practice: serviceOutput für ausgestellte Dokumente

Gib das Ergebnis der Dienstleistung über serviceOutput an: „Personalausweis", „Führerschein", „Elterngeld-Bescheid". Das stärkt die semantische Einordnung erheblich.

9. Fazit und Checkliste

GovernmentService Schema Markup ist eine der unterschätzten Chancen im öffentlichen Sektor. Behörden und Kommunen, die ihre Dienstleistungsseiten mit korrektem JSON-LD ausstatten, verbessern ihre Sichtbarkeit für Bürgeranfragen und reduzieren gleichzeitig den Beratungsbedarf — weil Bürger direkt auf der richtigen Seite landen.

GovernmentService Checkliste

  • ✓ GovernmentService nur auf Dienstleistungsseiten (nicht auf der Behörden-Startseite)
  • ✓ name, serviceType und description ausfüllen
  • ✓ areaServed mit Gemeinde oder Landkreis angeben
  • ✓ provider als GovernmentOrganization verknüpfen
  • ✓ Alle Zugangswege über availableChannel (ServiceChannel) angeben
  • ✓ hoursAvailable für Öffnungszeiten setzen
  • ✓ serviceOutput für das ausgestellte Dokument angeben
  • ✓ audience für die Zielgruppe des Dienstes eintragen
  • ✓ Im Google Rich Results Test validieren
