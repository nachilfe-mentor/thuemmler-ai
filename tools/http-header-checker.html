Was prüft der HTTP Header Checker?

X-Robots-Tag

Steuert die Indexierung über HTTP - unabhängig vom Meta-Robots-Tag. Kritisch: noindex hier verhindert das Ranking komplett.

Cache-Control

Steuert, wie Browser und CDNs Seiten zwischenspeichern. Ohne Caching laden Seiten bei jedem Aufruf neu - schlechter für Ladezeit und Core Web Vitals.

HSTS

Strict-Transport-Security erzwingt HTTPS und verhindert Downgrade-Angriffe. Google bevorzugt HTTPS-Seiten - HSTS ist der nächste Sicherheitsschritt.

Content-Encoding (Komprimierung)

Gzip oder Brotli komprimiert HTML/CSS/JS bis zu 80 %. Ohne Komprimierung laden Seiten deutlich langsamer - direkter Einfluss auf LCP und Core Web Vitals.

ETag / Last-Modified

Ermöglichen bedingte Requests - Browser fragen, ob sich die Seite geändert hat, bevor sie sie neu laden. Reduziert Bandbreite und verbessert Wiederholungsbesuche.

Server-Informationen

Server und X-Powered-By verraten Technologie-Stack und Versionen - ein Sicherheitsrisiko. Besser: diese Header nicht ausliefern.
