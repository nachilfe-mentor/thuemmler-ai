Voraussetzungen für Google News Rich Results

  • ✓ Deine Website muss als News-Publisher bei Google registriert sein
  • ✓ Artikel muss primär ein Faktencheck sein (kein redaktioneller Kommentar)
  • ✓ Die Behauptung muss aus einer öffentlichen Quelle stammen
  • ✓ Datum des Faktenchecks und des Claims müssen angegeben sein
  • ✓ Reviewer muss die prüfende Organisation sein, nicht eine Einzelperson

So bindest du das Markup ein

  1. 1. Kopiere den generierten Code mit dem Button oben
  2. 2. Füge ihn in den <head>-Bereich deiner Faktencheck-Seite ein
  3. 3. Überprüfe das Markup im Google Rich Results Test
  4. 4. Reiche deine Seite in der Search Console zur Indexierung ein
