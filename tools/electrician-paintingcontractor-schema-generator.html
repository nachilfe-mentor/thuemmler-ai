Was ist Electrician Schema Markup?

Electrician und PaintingContractor sind spezialisierte Schema.org-Typen für Elektrobetriebe und Malerbetriebe. Korrekt implementiert aktivieren sie Bewertungssterne, Öffnungszeiten und Adressbox direkt in Google-Suchergebnissen.

So verwendest du das generierte Schema Markup

📝

1. Formular ausfüllen

Gib alle Informationen über deinen Elektro- oder Malerbetrieb ein. Je vollständiger, desto besser für Google.

📋

2. JSON-LD kopieren

Klicke auf "Kopieren" und füge den Code in den <head>-Bereich deiner Website ein — zwischen <script type="application/ld+json"> Tags.

🔍

3. Validieren und Live stellen

Prüfe das Markup mit unserem JSON-LD Validator und stelle die Seite live. Google wertet das Markup beim nächsten Crawl aus.
