Was sind Core Web Vitals?

Core Web Vitals (CWV) sind drei Google-Ranking-Faktoren, die die Nutzererfahrung einer Website messen. Seit dem Google Page Experience Update 2021 fließen sie direkt in das Ranking ein.

🖼️ LCP – Largest Contentful Paint

Misst, wie lange das größte sichtbare Element (Bild, Text, Video) braucht, um geladen zu werden. Ein schlechter LCP entsteht durch langsame Server, große Bilder oder render-blockierende Ressourcen.

📐 CLS – Cumulative Layout Shift

Misst unerwartete Layoutverschiebungen während des Ladens. Häufige Ursachen: Bilder ohne definierte Größe, dynamisch eingefügte Inhalte (Ads, Cookies) oder Webfonts die Texte verschieben.

⚡ INP – Interaction to Next Paint

Seit März 2024 ersetzt INP den alten FID. Es misst die Latenz aller Nutzerinteraktionen (Klicks, Tastendrücke) auf der Seite — nicht nur die erste. Schwere JS-Tasks sind die Hauptursache.

🔍 Lab-Daten vs. Felddaten

Dieses Tool zeigt Lab-Daten — gemessen in einer kontrollierten Umgebung. Googles Ranking-Entscheidungen basieren primär auf Felddaten (CrUX – echte Nutzerdaten). Beide ergänzen sich.
