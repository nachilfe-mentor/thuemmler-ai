SoftwareApplication Schema Generator

JSON-LD für WebApplication, MobileApplication und Desktop-Apps kostenlos erstellen — für Google Rich Results und bessere App-Sichtbarkeit in der Suche.

Generiertes JSON-LD


                    


                    
                    

                        
So binden Sie das Markup ein

                        
Fügen Sie den generierten Code in den <head>-Bereich Ihrer App-Seite ein:

                        
<head>
  ...
  <script type="application/ld+json">
  { ... Ihr generiertes JSON-LD ... }
  </script>
</head>

                    


                    
                    

                        
Die richtigen App-Typen wählen

                        

                            

                                WebApplication
                                Browser-basierte Apps und SaaS-Tools — kein Download nötig
                            

                            

                                MobileApplication
                                Smartphone-Apps (iOS / Android), die heruntergeladen werden
                            

                            

                                VideoGame
                                Spiele — egal ob Mobile, Browser oder Desktop
                            

                            

                                DesktopApplication
                                Programme für Windows, macOS oder Linux
                            

                            

                                SoftwareApplication
                                Allgemeiner Typ, wenn kein spezifischer Untertyp passt
                            

                        

                    

                

            


            
            

                

                    
📱

                    
Mobile vs. Web

                    
Für iOS/Android-Apps nutzen Sie MobileApplication. Für Browser-Apps wie SaaS-Tools WebApplication. Bei beiden: setzen Sie downloadUrl auf den App-Store-Link.

                

                

                    
⭐

                    
Bewertungen

                    
Echte Bewertungen mit aggregateRating können als Sterne-Snippets in den Google-Suchergebnissen erscheinen — besonders bei Mobile-App-Suchen sehr effektiv.

                

                

                    
✅

                    
Validierung

                    
Testen Sie Ihr Markup mit Googles Rich Results Test oder unserem JSON-LD Validator.
