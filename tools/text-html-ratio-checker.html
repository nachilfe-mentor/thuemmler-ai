Was ist das Text-zu-HTML-Ratio?

📐

Definition

Das Text-zu-HTML-Ratio gibt an, wie viel Prozent deiner Seite aus sichtbarem Text bestehen — im Verhältnis zum gesamten HTML-Code. Ein Wert von 25% bedeutet: Ein Viertel des HTML-Codes ist sichtbarer Text, drei Viertel sind Tags, Scripts und Styles.

🎯

Optimaler Bereich

Suchmaschinen bevorzugen Seiten mit einem Text/HTML-Ratio zwischen 25% und 70%. Unter 10% deutet auf Code-Bloat oder dünn besetzten Content hin. Über 70% ist ebenfalls möglich — wichtiger ist die absolute Textmenge und -qualität.

⚡

Warum ist es SEO-relevant?

Google crawlt deinen HTML-Code, um Inhalte zu verstehen. Je größer das Verhältnis von Code zu Text, desto mehr "Rauschen" muss der Crawler durchdringen, um den eigentlichen Inhalt zu finden. Schlanker Code mit viel relevantem Text erleichtert das Crawlen und Indexieren.

🔧

Wie verbessern?

  • • CSS und JavaScript in externe Dateien auslagern
  • • Unnötige HTML-Kommentare entfernen
  • • Redundante verschachtelte Tags reduzieren
  • • Mehr hochwertigen Textinhalt hinzufügen
  • • Inline-Styles durch CSS-Klassen ersetzen
