Was ist ein Performance-Budget?

Die Idee

Ein Performance-Budget ist eine selbst gesetzte Obergrenze für das Gewicht deiner Website. Statt erst nach dem Launch zu messen, ob die Seite zu langsam ist, legst du vorher fest: „Meine Startseite darf höchstens X Kilobyte übertragen." Jede neue Schriftart, jedes Karussell und jedes Tracking-Skript muss sich in dieses Budget einfügen — sonst muss etwas anderes weichen.

Wie dieses Tool rechnet

Aus deiner Ziel-Ladezeit und der angenommenen Verbindungsgeschwindigkeit deiner Besucher errechnet der Planer das maximale Übertragungsbudget. Davon zieht er einen Puffer für Netzwerk-Latenz und Rendering ab und verteilt den Rest nach bewährten Anteilen auf HTML, CSS, JavaScript, Bilder und Schriften.

Warum die langsame Verbindung zählt

Google bewertet die mobile Performance unter realistischen, eher langsamen Bedingungen (Lighthouse simuliert ein „langsames 4G"). Wer sein Budget nur für schnelles WLAN plant, fällt bei echten Nutzern und in den Core Web Vitals durch. Plane deshalb konservativ für die Verbindung deiner schwächsten relevanten Zielgruppe.

So hältst du dein Budget ein

  • Bilder: moderne Formate (WebP/AVIF), korrekte Größen, Lazy Loading.
  • JavaScript: Code-Splitting, ungenutzte Bibliotheken entfernen, Third-Party-Skripte prüfen.
  • Schriften: nur benötigte Schnitte laden, font-display: swap.
  • CSS: Critical CSS inline, ungenutzte Regeln entfernen.

Mehr zum Thema findest du in unseren Leitfäden Core Web Vitals verbessern, Bildoptimierung mit WebP und AVIF und Critical CSS extrahieren. Zum Messen deiner tatsächlichen Werte hilft der Core-Web-Vitals-Checker.

Datenschutz: Die Berechnung läuft zu 100 % in deinem Browser. Es werden keine Daten an einen Server gesendet, gespeichert oder protokolliert.
