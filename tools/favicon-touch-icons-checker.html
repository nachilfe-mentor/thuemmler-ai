Alle Icon-Typen erklärt

            

                

                    
🌐

                    
Standard-Favicon

                    
Das klassische favicon.ico oder <link rel="icon"> wird in Browser-Tabs, Lesezeichen und der Adressleiste angezeigt. Mindestgröße: 16×16 px. Empfohlen: 32×32 px als PNG.

                

                

                    
🍎

                    
Apple Touch Icon

                    
Wird auf iOS-Geräten verwendet, wenn Nutzer deine Website zum Home-Bildschirm hinzufügen. Die optimale Größe ist 180×180 px (apple-touch-icon). Ohne dieses Icon verwendet iOS einen Screenshot – kein schöner Anblick.

                

                

                    
📱

                    
Web App Manifest

                    
<link rel="manifest"> verweist auf eine JSON-Datei mit App-Metadaten. Pflicht für PWAs und Android Home Screen. Enthält Icons in 192×192 und 512×512 px. Auch für normale Websites sehr empfohlen.

                

                

                    
🦊

                    
Safari Mask Icon (SVG)

                    
<link rel="mask-icon"> mit einer SVG-Datei und color-Attribut wird in Safari für das gepinnte Tab-Icon genutzt. Das SVG sollte einfarbig/monochrom sein – die Farbe wird über das color-Attribut gesetzt.

                

                

                    
🎨

                    
Theme Color

                    
<meta name="theme-color"> coloriert die Browser-Adressleiste auf Android Chrome und in Progressive Web Apps. Stärkt die Markenidentität und macht die Website professioneller.

                

                

                    
🪟

                    
MS Application Tile

                    
<meta name="msapplication-TileImage"> und msapplication-TileColor definieren das Icon für Windows-Kacheln (Start-Menü, Taskleiste). Für Websites mit viel Windows-Traffic relevant.

                

            


            
Optimale Favicon-Einbindung (Beispiel)

            

                
<!-- Standard Favicon (32×32 PNG + ICO Fallback) -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="shortcut icon" href="/favicon.ico">

<!-- Apple Touch Icon (iOS Home Screen) -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

<!-- Web App Manifest (Android + PWA) -->
<link rel="manifest" href="/site.webmanifest">

<!-- Safari Mask Icon -->
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#1e3a8a">

<!-- Theme Color (Android Chrome) -->
<meta name="theme-color" content="#1e3a8a">

<!-- Windows Tile -->
<meta name="msapplication-TileColor" content="#1e3a8a">
<meta name="msapplication-TileImage" content="/mstile-150x150.png">
