ℹ️ Was ist IndexNow?

IndexNow ist ein offenes Protokoll, das es Website-Betreibern erlaubt, neue und geänderte URLs direkt an Suchmaschinen zu melden - anstatt auf den nächsten Crawl zu warten. Entwickelt von Microsoft (Bing) und Yandex, unterstützt es inzwischen mehrere Suchmaschinen gleichzeitig.

Statt Tage oder Wochen auf eine Neuindexierung zu warten, kann Google und Bing innerhalb von Stunden informiert werden. Du brauchst nur einen API-Schlüssel (eine Textdatei auf deiner Domain) und die URLs, die du einreichen möchtest.

                    URLs gehören nicht zum Host

✓ Best Practices

            
    
                
  • ✓ Nur URLs einreichen, die sich wirklich geändert haben oder neu sind
    • 
                
  • ✓ Maximal 10.000 URLs pro API-Call
    • 
                
  • ✓ URLs müssen mit dem angegebenen Host übereinstimmen
    • 
                
  • ✓ Nur öffentlich zugängliche Seiten einreichen (keine Login-Seiten)
    • 
                
  • ✓ Schlüsseldatei muss über die richtige URL erreichbar sein
    • 
                
  • ⚠ Google nutzt IndexNow noch nicht (eigene Search Console verwenden)
