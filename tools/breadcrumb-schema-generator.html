Warum Breadcrumb Schema wichtig ist

Rich Snippets in Google

Google zeigt Breadcrumbs direkt unter dem Seitentitel in den Suchergebnissen. Das erhöht die Klickrate (CTR) deutlich.

Seitenstruktur kommunizieren

Breadcrumb Schema zeigt Google, wie deine Seiten hierarchisch aufgebaut sind — das hilft bei der Einordnung in Themenbereiche.

Kein Plugin nötig

Einfach den generierten Code im <head>-Bereich jeder Seite einfügen. Funktioniert mit jeder Website — kein CMS-Plugin erforderlich.

So verwendest du den generierten Code

1

Breadcrumb-Ebenen eingeben

Trage alle Ebenen deiner Navigation ein (z.B. Startseite → Kategorie → Artikel). Die letzte Ebene ist die aktuelle Seite — URL ist optional.

2

JSON-LD generieren und kopieren

Klicke auf "Generieren" und kopiere den fertigen Code. Er ist sofort einsatzbereit.

3

Im <head> deiner Seite einfügen

Füge den <script type="application/ld+json">-Block in den <head>-Bereich der jeweiligen Seite ein — für jede Seite mit eigener Breadcrumb-Navigation separat.

4

In Google's Rich Results Test prüfen

Teste deine Seite im Rich Results Test von Google, um sicherzustellen, dass der Code korrekt erkannt wird.
