Hreflang-Tag-Generator

Generiere korrekten hreflang-Code für mehrsprachige Websites. Füge URL-Sprachpaare hinzu und erhalte sofort einfügfertigen HTML-Code.

So funktioniert's:

  1. Gib für jede Sprachversion die URL und den Sprachcode ein (z.B. de, en, de-AT)
  2. Füge beliebig viele Zeilen hinzu — für jede Sprachversion eine
  3. Kopiere den generierten Code in den <head> aller Sprachversionen
  4. Optional: Aktiviere "x-default" für die Fallback-Seite (empfohlen)

Wichtige Regeln

                    
    
                        
  • • Jede URL muss auf alle anderen Sprachversionen verweisen (bidirektional)
    • 
                        
  • • Jede Seite muss sich auch selbst verlinken (self-referencing hreflang)
    • 
                        
  • • URLs müssen absolut sein (mit https://)
    • 
                        
  • • Sprachcodes nach ISO 639-1, Ländercodes nach ISO 3166-1 alpha-2
    • 
                    

                

            

        

    


    
    

        

            
Häufige Hreflang-Fehler

            
    
                
  • ❌ Einseitige Verlinkung — Seite A verlinkt auf B, aber B nicht auf A
    • 
                
  • ❌ Fehlende Selbstverlinkung — Jede Seite muss sich auch selbst referenzieren
    • 
                
  • ❌ Falsche Sprachcodes — "german" statt "de", "english" statt "en"
    • 
                
  • ❌ Relative URLs — Alle URLs müssen absolut sein (mit https://)
    • 
                
  • ❌ Fehlendes x-default — Ohne Fallback kein Schutz vor Länder-Konflikten
    • 
                
  • ❌ Nur auf einer Seite — Code muss auf allen Sprachversionen identisch sein
    • 
            

        

        

            
Wann brauchst du Hreflang?

            
    
                
  • ✅ Verschiedene Sprachversionen (de/en/fr)
    • 
                
  • ✅ Gleiche Sprache, verschiedene Länder (de-DE / de-AT)
    • 
                
  • ✅ Gleicher Inhalt in mehreren Varianten (en-US / en-GB)
    • 
                
  • ❌ Verschiedene Inhalte auf derselben Sprache → kein Hreflang nötig
    • 
                
  • ❌ Nur ein Land/eine Sprache → kein Hreflang nötig
    •
