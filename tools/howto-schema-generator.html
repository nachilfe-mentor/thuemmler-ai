Was ist HowTo Schema Markup?

HowTo Schema (schema.org/HowTo) ist ein strukturiertes Datenformat, das Suchmaschinen mitteilt, dass eine Seite eine Schritt-für-Schritt-Anleitung enthält. Google kann diese Informationen nutzen, um How-to Rich Snippets anzuzeigen - erweiterte Suchergebnisse mit einzelnen Schritten direkt in der SERP.
